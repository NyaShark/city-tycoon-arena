# 都市大亨：环城争霸

一个可直接在浏览器运行的单页大富翁式城市经营游戏。无需安装依赖，支持桌面与移动端。

## 玩法

- 2–4 名玩家本地对局，可混合真人和三档 AI 对手
- 40 格环城棋盘、24 处地产、8 个地产组合、4 座交通枢纽、3 家公用事业
- 买入、均衡升级、组合租金、抵押、赎回、公开拍卖和破产清算
- 三支股票、交易手续费、持仓股息和每回合价格波动
- 调整期、平稳期与扩张期组成楼市周期，影响租金、股价和事件
- 城市事件、税务、看守所、基金池、市政厅和自动本地存档

## 本地运行

```bash
npm run serve
```

打开 `http://127.0.0.1:4173`。

## 测试

```bash
npm test
```

规则引擎测试覆盖地产组合、租金、均衡升级、抵押、股票、拍卖、破产和存档恢复。
